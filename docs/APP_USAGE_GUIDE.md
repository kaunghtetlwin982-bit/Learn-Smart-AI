# Learn Smart AI – App Usage Guide

ဒီလမ်းညွှန်သည် လက်ရှိ project ထဲရှိ screen၊ button နှင့် data များကို စစ်ဆေးပြီး ရေးထားခြင်းဖြစ်သည်။ မျက်နှာပြင်စာသားကို English သို့မဟုတ် မြန်မာဘာသာဖြင့် ပြောင်းနိုင်သည်။ အောက်တွင် အသုံးပြုသူမြင်ရသော အမည်များကို လိုအပ်သည့်နေရာတွင် English ဖြင့် ဖော်ပြထားသည်။

## 1. Learn Smart AI ဆိုတာဘာလဲ?

Learn Smart AI သည် Grade 11 ကျောင်းသား/သူအတွက် မေးခွန်းများဖတ်ရန်၊ အဖြေနှင့် ရှင်းလင်းချက်ကြည့်ရန်၊ quiz ဖြေရန်၊ သင်ခန်းစာဗီဒီယိုလင့်ခ်များရှာရန်နှင့် AI Tutor ကို မေးရန် ပြုလုပ်ထားသော လေ့လာရေး app တစ်ခုဖြစ်သည်။ Mathematics, Physics, Chemistry, Biology နှင့် English ဘာသာရပ်ငါးခု ပါဝင်သည်။

လေ့လာစရာများကို တစ်နေရာတည်းတွင် ရှာဖွေပြီး ကိုယ်တိုင်လေ့ကျင့်နိုင်ရန် ကူညီသည်။ လက်ရှိ content အများစုသည် app ထဲတွင် ကြိုတင်ထည့်ထားသော နမူနာစာရင်းများဖြစ်ပြီး ကျောင်း၏ တရားဝင်သင်ရိုး သို့မဟုတ် ကျောင်းသားတစ်ဦးချင်း၏ တကယ့်စာမေးပွဲမှတ်တမ်းဟု မယူဆသင့်ပါ။

## 2. App ကို စတင်အသုံးပြုခြင်း

လက်ရှိ project ကို browser ဖြင့်ဖွင့်ရသော web app အဖြစ် ပြုလုပ်ထားသည်။ ပုံမှန်အသုံးပြုသူအတွက် ဝဘ်ဆိုက်လိပ်စာကို ဖွင့်ပါ။ ဒီ project တွင် account ဝင်ရန် သို့မဟုတ် အမည်/စကားဝှက်ဖြည့်ရန် screen မရှိပါ။

ပထမဆုံးမြင်ရမည့် screen သည် **Home** ဖြစ်သည်။ ခေါင်းစီးတွင် “Learn Smart AI” နှင့် Grade 11/2026 စာသား၊ ရှာဖွေရေးအကွက်နှင့် အောက်တွင် လေ့လာရေးအပိုင်းများကို မြင်ရသည်။ App ကို အများဆုံး 430px အကျယ်ရှိ ဖုန်းပုံစံအပြင်အဆင်ဖြင့် ပြထားသည်။

အောက်ခြေ navigation တွင် **Home**, **Questions**, **Saved**, **Me** ဟူသော tab လေးခုရှိသည်။ Quiz၊ AI Tutor နှင့် Resources ကဲ့သို့ အချို့ screen များသည် သီးခြားအပြည့်မျက်နှာပြင်ပုံစံဖြစ်ပြီး ၎င်းတို့အတွင်းတွင် အောက်ခြေ tab bar မပေါ်ပါ။

## 3. Home Screen

- **Search questions, topics…** — မေးခွန်းခေါင်းစဉ်၊ မေးခွန်းစာသား သို့မဟုတ် ဘာသာရပ်အမည်ကို ရိုက်ရှာသည်။ ရလဒ်တစ်ခုကိုနှိပ်လျှင် မေးခွန်းအသေးစိတ်သို့ သွားသည်။ အများဆုံး ရလဒ် ၆ ခုသာ ပြသည်။
- **Learning Topics / Saved / Subjects** — 18 topics၊ သိမ်းထားသောမေးခွန်းအရေအတွက်နှင့် ဘာသာရပ် ၅ ခုကို ပြသသော အကျဉ်းချုပ်ကိန်းဂဏန်းများဖြစ်သည်။ 18 သည် သီးခြားရေတွက်ထားသော topic catalog မဟုတ်ဘဲ Home တွင်ပေးထားသော တန်ဖိုးဖြစ်သည်။
- **Quick Quiz** card — Quiz ပြင်ဆင်မှု screen သို့ သွားသည်။
- **Continue Learning** — “Simplify Algebraic Expressions” မေးခွန်းအသေးစိတ်သို့ သွားသည်။ 65% progress bar သည် ပုံသေပြထားသော ဒီဇိုင်းတန်ဖိုးဖြစ်သည်။
- **Subjects** — ဘာသာရပ် icon ကိုနှိပ်လျှင် Questions ကို ထိုဘာသာရပ်အလိုက် စစ်ထုတ်ပြီး ဖွင့်သည်။ **View all** သည် ဘာသာရပ်အားလုံးပါဝင်သော Question Bank သို့ သွားသည်။
- **Progress Overview** — ဘာသာရပ်အလိုက် တိုးတက်မှုရာခိုင်နှုန်းကို ပြသည်။ ၎င်းသည် ပုံသေ demo တန်ဖိုးများဖြစ်သည်။
- **Recent Questions** — ပထမဆုံးမေးခွန်းငါးခုကို ပြသည်။ တစ်ခုကိုနှိပ်လျှင် အသေးစိတ်ဖတ်နိုင်သည်။ **See all** သည် Question Bank သို့ သွားသည်။
- **Saved Questions** အကျဉ်းကတ် — သိမ်းထားသည့်မေးခွန်းများသို့ သွားသည်။ အစပိုင်းတွင် မေးခွန်း ၃ ခုကို ကြိုသိမ်းထားသည်။

## 4. Question Bank

အောက်ခြေရှိ **Questions** ကိုနှိပ်ပါ၊ သို့မဟုတ် Home ရှိ ဘာသာရပ်/See all ကိုသုံးပါ။ ဘာသာရပ်ငါးခု၊ အခန်း (chapter) နှင့် Easy/Medium/Hard အဆင့်များဖြင့် စစ်ထုတ်နိုင်သည်။ ဘာသာရပ်ရွေးပြီးမှ ထိုဘာသာရပ်၏ အခန်းများ ပေါ်လာသည်။ Search သည် မေးခွန်းခေါင်းစဉ်နှင့် မေးခွန်းစာသားကို ရှာသည်။ စစ်ထုတ်မှုအားလုံးကို **Clear Filters** ဖြင့် ပြန်ရှင်းနိုင်သည်။

မေးခွန်းကတ်ကိုနှိပ်လျှင် အသေးစိတ် screen သို့သွားပြီး မေးခွန်း၊ အဖြေနှင့် ရှင်းလင်းချက်တို့ကို တစ်ခါတည်းမြင်ရသည်။ ကတ်ပေါ်က bookmark ကိုနှိပ်လျှင် သိမ်း/ဖြုတ်နိုင်သည်။ အသေးစိတ်တွင်လည်း **Save Question** ကိုနှိပ်နိုင်သည်။ ဒါသည် ကိုယ်တိုင်စဉ်းစားပြီးမှ အဖြေဖွင့်သည့် quiz ပုံစံ မဟုတ်ပါ—Question Bank detail တွင် အဖြေကို တန်းပြထားသည်။

**Ask AI** သည် ထိုမေးခွန်းအကြောင်းအရာကို တွဲပို့ပြီး Tutor ကိုဖွင့်သည်။ **Resources** သည် ထိုဘာသာရပ်/အခန်း/ခေါင်းစဉ်နှင့် ကိုက်ညီစေရန် ရွေးထားသော Resources screen ကိုဖွင့်သည်။ အသေးစိတ် screen ၏ နောက်ပြန်မြှားက ယခင် screen သို့ ပြန်ပို့သည်။

## 5. Quiz

Home ရှိ **Quick Quiz** ကိုနှိပ်ပါ။ ပြင်ဆင်မှုတွင် ဘာသာရပ်၊ difficulty နှင့် မေးခွန်းအရေအတွက်ကို ရွေးပါ။ မေးခွန်း ၁၀ ခုသာ ရှိသော quiz bank ထဲမှ ကိုက်ညီသောမေးခွန်းများကို အသုံးပြုသည်။ ရနိုင်သမျှထက် ပိုမရွေးနိုင်ပါ။

**Start Quiz** ကိုနှိပ်လျှင် ရနိုင်သောမေးခွန်းများကို ကျပန်းအစီအစဉ်ပြောင်းပြီး ရွေးထားသောအရေအတွက် ယူသည်။ ရွေးချယ်စရာလေးခု၏ အစီအစဉ်လည်း ကျပန်းပြောင်းသည်။ မေးခွန်းတစ်ခုစီတွင် အဖြေတစ်ခုကိုနှိပ်ပါ။ တစ်ခါရွေးပြီးလျှင် ပြန်မပြောင်းနိုင်ပါ။ မှန်လျှင် အစိမ်းရောင်၊ မှားလျှင် ရွေးထားသည့်အဖြေကို အနီရောင်နှင့် အဖြေမှန်ကို အစိမ်းရောင်ပြပြီး ရှင်းလင်းချက်ပေးသည်။ ထို့နောက် **Next Question** ကိုနှိပ်ပါ။ နောက်ပြန်သွားပြီး အဖြေပြောင်းနိုင်သော မေးခွန်းလမ်းကြောင်း မရှိပါ။

အပေါ်တွင် လက်ရှိအမှတ်နှင့် မေးခွန်းတိုးတက်မှု bar ကိုမြင်ရသည်။ အဆုံးတွင် မှန်/မှားအရေအတွက်၊ စုစုပေါင်းရမှတ်နှင့် ရာခိုင်နှုန်းကို ပြသည်။ **Retry Quiz** သည် ထို filter များအတိုင်း ကျပန်းမေးခွန်းအသစ်ဖြင့် ပြန်စသည်။ **Back to Home** သည် Home သို့သွားသည်။ ခေါင်းစီးနောက်ပြန်မြှားက Quiz မှထွက်ပြီး ယခင် screen သို့ ပြန်သွားသည်။ Quiz ရမှတ်ကို Progress screen ထဲသို့ သိမ်းပေါင်းမထားပါ။

Quiz စတင်၊ အဖြေမှန်/မှားနှင့် ပြီးဆုံးချိန်တွင် sound effect များရှိသည်။ Background music ဖွင့်ထားလျှင် loop ပတ်ဖွင့်ရန် ကြိုးစားသည်။

## 6. AI Tutor

Question Bank ထဲရှိ မေးခွန်းတစ်ခုကိုဖွင့်ပြီး **Ask AI** ကိုနှိပ်ပါ။ မေးခွန်းမှလာပါက Tutor က ၎င်း၏ဘာသာရပ်၊ အခန်း၊ မေးခွန်း၊ အဖြေနှင့် ရှင်းလင်းချက်ကို နောက်ခံဝန်ဆောင်မှုထံ context အဖြစ် ပို့သည်။ စာရိုက်ပြီး **Send** ခလုတ်ကိုနှိပ်ပါ၊ သို့မဟုတ် Enter နှိပ်ပါ (Shift+Enter သည် စာကြောင်းအသစ်)။ စဉ်းစားနေကြောင်း “AI Tutor is thinking…” ဟုပြပြီး အဖြေကို chat bubble ဖြင့်ပြသည်။ ပထမဦးဆုံးတွင် ရှင်းပြရန်၊ ပိုလွယ်အောင်ရှင်းပြရန်၊ ဥပမာတောင်းရန် quick buttons ရှိသည်။

**အရေးကြီးသော လက်ရှိကန့်သတ်ချက်:** AI သည် UI ထဲက ကြိုတင်ရေးထားသော အဖြေမဟုတ်ပါ။ Browser သည် `/api/ai` ကိုခေါ်ပြီး `api/ai.ts` handler က သတ်မှတ်ထားသော ပြင်ပ OpenAI-compatible ဝန်ဆောင်မှုကို ခေါ်ရန် ရေးထားသည်။ သို့သော် project README အရ ဒီ repository သည် Vite frontend သာဖြစ်ပြီး serverless backend ကို ကိုယ်တိုင်မပါဝင်ပါ။ Server ပေါ်တွင် handler ကို `/api/ai` အဖြစ် deploy လုပ်ပြီး `AI_API_KEY`, `AI_API_BASE_URL`, `AI_MODEL` သတ်မှတ်ထားမှသာ အမှန်တကယ် AI အဖြေ ရနိုင်သည်။ Vite preview/local frontend တစ်ခုတည်းတွင် ပုံမှန်အားဖြင့် မရနိုင်ဘဲ အမှားရှိပါက “Sorry, I couldn't answer right now…” ကိုပြသည်။ ကွန်ယက်နှင့် API ဝန်ဆောင်မှုလိုအပ်သည်။

## 7. Learning Resources

မေးခွန်းအသေးစိတ်ထဲက **Resources** ကိုနှိပ်ပြီး ဝင်ပါ။ ဘာသာရပ်ရွေး၍ ဗီဒီယိုစာရင်းကို စစ်ထုတ်နိုင်သည်။ ယခုစာရင်းတွင် YouTube လင့်ခ် ၁၇ ခုရှိပြီး card တစ်ခုစီ၌ thumbnail၊ ခေါင်းစဉ်နှင့် ဘာသာရပ်ကို ပြသည်။ အခန်းနှင့် topic context ကို Question detail မှပေးပို့နိုင်သည်။

## 8. Progress

Progress ကို **Me** tab မှဝင်ပြီး **View detailed progress** သို့မဟုတ် Settings ထဲက Progress ကိုနှိပ်၍ ကြည့်ပါ။ ပြထားသည့်အချက်များမှာ ယခုဖွင့်ထားစဉ် ကြည့်ဖူးသော မေးခွန်းအရေအတွက်၊ လက်ရှိသိမ်းထားသောမေးခွန်းအရေအတွက်၊ ဘာသာရပ်ငါးခု၏ ရာခိုင်နှုန်းနှင့် ပုံသေ study tip တို့ဖြစ်သည်။

`viewed` count သည် အသေးစိတ်ဖွင့်ခဲ့သော မေးခွန်း ID များကို app ဖွင့်ထားသည့် session အတွင်းသာ ရေတွက်ပြီး page ပြန်ဖွင့်လျှင် သုညမှစသည်။ Subject progress (70%, 55%, 80%, 75%, 60%) နှင့် Home progress bar များသည် code ထဲက static demo data ဖြစ်ပြီး သင်၏လုပ်ဆောင်ချက်မှတွက်ထားခြင်း မဟုတ်ပါ။ Saved count သည် လက်ရှိ app session ထဲရှိ saved set ကိုရေတွက်ပြီး ပြန်ဖွင့်လျှင် မူလမေးခွန်း ၃ ခုသို့ ပြန်သွားသည်။ Quiz score ကိုလည်း မှတ်တမ်းမတင်ပါ။

## 9. Profile (Me)

**Me** tab တွင် ပုံသေ profile အမည် “Khin Eaidra Min”, “Grade 11 Student”, 2026 Academic Year နှင့် avatar အက္ခရာ “KM” ကိုပြသည်။ ဤအမည်နှင့် profile ကို ပြင်ရန် form မရှိပါ။ Viewed/Saved ကိန်းများသည် လက်ရှိ app အခြေအနေ၊ overall progress သည် ဘာသာရပ်ရာခိုင်နှုန်းငါးခု၏ ပျမ်းမျှဖြစ်ပြီး 68% ဖြစ်သည်။

အသုံးပြုသူပြောင်းနိုင်သည့်အရာများမှာ Language (English/မြန်မာ), Appearance (Light/Dark), Sound Effects နှင့် Background Music တို့ဖြစ်သည်။ Language, appearance နှင့် audio ရွေးချယ်မှုများကို local device/browser storage ထဲတွင် မှတ်ထားသည်။ Notifications switch သည် on/off အခြေအနေကိုသာ မှတ်ထားသည်; သတိပေး notification အမှန်တကယ်ပို့သည့်စနစ် မတွေ့ရပါ။ **Question Bank**, **Saved**, **Progress** shortcut များ အလုပ်လုပ်သည်။ About, Privacy Policy, Rate the App, Send Feedback တို့သည် စာရင်းအဖြစ်သာ ရှိပြီး လင့်ခ်/လုပ်ဆောင်ချက် မချိတ်ထားပါ။

## 10. Audio / Music

Profile > Settings ထဲက **Sound Effects** နှင့် **Background Music** switch များကိုနှိပ်ပါ။ Sound Effects ကို default ဖွင့်ထားပြီး Background Music ကို default ပိတ်ထားသည်။ ရွေးချယ်မှုကို browser/device ထဲတွင် မှတ်ထားသည်။

Sound effect များသည် Quiz စတင်ချိန်၊ အဖြေရွေးပြီး မှန်/မှားသည့်အချိန်နှင့် quiz ပြီးသည့်အချိန်တွင်သာ ခေါ်သုံးထားသည်။ Background music ဖွင့်ထားပါက app အတွင်း အခြား screen များသို့သွားသော်လည်း provider တစ်ခုတည်းတည်ရှိနေသရွေ့ loop ဆက်ဖွင့်ရန် ရေးထားသည်။ ပိတ်လိုက်လျှင် ချက်ချင်းရပ်သည်။ Browser သည် အသုံးပြုသူမထိတွေ့မီ အသံဖွင့်ခြင်းကို တားနိုင်သောကြောင့် toggle ကိုဖွင့်ပြီးနောက် tap/click တစ်ကြိမ်လိုနိုင်သည်။ အသံဖွင့်မရလျှင် app က error မပြဘဲ ဆက်သုံးခွင့်ပေးသည်။ Audio ဖိုင်များကို PWA cache စာရင်းထဲ မထည့်ထားသောကြောင့် offline တွင် အသံမရနိုင်ပါ။

## 14. Common User Actions

1. **Quiz စရန်:** Home > Quick Quiz > subject/difficulty/count ရွေး > Start Quiz.
2. **မေးခွန်းဖြေရန်:** Quiz ထဲက ရွေးချယ်စရာတစ်ခုကိုနှိပ် > feedback ဖတ် > Next Question. Question Bank detail တွင် အဖြေကို ဖတ်ရုံဖြစ်သည်။
3. **AI ကိုမေးရန်:** Questions > မေးခွန်းတစ်ခုဖွင့် > Ask AI > မေးခွန်းရိုက် > Send. အမှန်တကယ်အဖြေအတွက် AI backend deploy လုပ်ထားရန်လိုသည်။
4. **Resource ကြည့်ရန်:** မေးခွန်းဖွင့် > Resources > Video card > Watch on YouTube. App ပြင်ပ YouTube ကိုဖွင့်သည်။
5. **Progress ကြည့်ရန်:** Me > View detailed progress.
6. **Home ပြန်ရန်:** Home tab ကိုနှိပ်ပါ။ Quiz result မှ Back to Home ကိုလည်းနှိပ်နိုင်သည်.
7. **အသံထိန်းချုပ်ရန်:** Me > Sound Effects သို့မဟုတ် Background Music switch ကိုပြောင်းပါ။ အသံမထွက်ပါက စက်၏အသံအတိုးအကျယ်နှင့် browser အသံဖွင့်ခွင့်ကို စစ်ပါ။
8. **မေးခွန်းသိမ်းရန်:** Question ကတ်၏ bookmark သို့မဟုတ် detail ထဲက Save Question ကိုနှိပ်; Saved tab မှ ပြန်ဖွင့်/ဖြုတ်နိုင်သည်။

## 17. PWA Install နှင့် အသုံးပြုခြင်း

### A. PWA ဆိုတာဘာလဲ?

PWA (Progressive Web App) သည် browser website တစ်ခုကို supported device/browser တွင် Home Screen သို့မဟုတ် app list ထဲ ထည့်ဖွင့်နိုင်စေသော နည်းလမ်းဖြစ်သည်။ ဒီ project တွင် Web App Manifest, icon များနှင့် service worker ရှိသည်။ သို့သော် install ခလုတ်ကို browser ကသာ ပြသဆုံးဖြတ်ပြီး browser/OS, secure HTTPS hosting နှင့် install လိုအပ်ချက်များအပေါ် မူတည်သည်။

### B. Install လုပ်နည်း

Install လုပ်ရန် deployed HTTPS website ကို supported browser ဖြင့်ဖွင့်ပါ (localhost သည် development အတွက် browser exception ဖြစ်နိုင်သည်)။ Project မှ install dialog ကို ကိုယ်တိုင်မပြပါ။

- **Desktop Chrome/Edge (ပံ့ပိုးထားပါက):** လိပ်စာဘား၏ ညာဘက် install icon ကိုနှိပ်၊ သို့မဟုတ် browser menu ထဲက **Install Learn Smart AI** / **Install page as app** ကိုရွေးပါ။ ထိုရွေးချယ်မှုမပေါ်ပါက ထို browser သို့မဟုတ် လက်ရှိ website အခြေအနေတွင် install မရနိုင်သေးပါ။
- **Android Chrome (ရနိုင်ပါက):** website ကိုဖွင့်ပြီး Chrome ၏ `⋮` menu ကိုဖွင့်ပါ။ **Install app** သို့မဟုတ် **Add to Home screen** ကိုရွေးပြီး ညွှန်ကြားချက်အတိုင်းလုပ်ပါ။ Menu အမည်သည် Chrome/Android version အလိုက် ကွာနိုင်သည်။
- **iPhone/iPad Safari:** Share ခလုတ် (စတုရန်းထဲမှ အပေါ်မြှား) > **Add to Home Screen** > **Add** ကိုရွေးပါ။ HTML shell ထဲတွင် Apple web app meta နှင့် touch icon ပါသည်။ Safari မှ Home Screen သို့ထည့်ခြင်းသည် Chrome install prompt နှင့်မတူဘဲ iOS version အလိုက် ကွာနိုင်သည်။

### C. Install လုပ်ပြီးနောက်

Browser/OS က install ကိုခွင့်ပြုလျှင် Learn Smart AI icon သည် Desktop, Start/app list သို့မဟုတ် ဖုန်း Home Screen ပေါ်တွင် ပေါ်လာမည်။ Icon ဖြင့်ဖွင့်သည့်အခါ manifest ထဲရှိ `display: standalone` ကြောင့် ပံ့ပိုးသော browser များတွင် browser toolbar/address bar မပါသော သီးခြား window/screen ပုံစံဖြင့် ဖွင့်လေ့ရှိသည်။ Native app ဖြစ်သွားခြင်းမဟုတ်ဘဲ web app အဖြစ်ပင် ရှိနေသည်။ Browser/OS အလိုက် ပုံစံကွာနိုင်သည်။

### D. အင်တာနက်မရှိဘဲ အသုံးပြုခြင်း

`src/main.tsx` သည် production အခြေအနေတွင် စာမျက်နှာဖွင့်ပြီးနောက် `/sw.js` ကို မှတ်ပုံတင်ရန် ကြိုးစားသည်။ Service worker သည် `/`, `/index.html`, manifest နှင့် icon များကို install လုပ်ချိန်တွင် cache ထဲသိမ်းပြီး build HTML တွင်ဖော်ပြသော same-origin JS/CSS ဖိုင်များကိုလည်း ရယူသိမ်းရန် ကြိုးစားသည်။ အင်တာနက်မရှိချိန်တွင် app ကိုဖွင့်သော request သည် cache ထဲရှိ `/index.html` ကို အသုံးပြုသည်။ ထို့ကြောင့် အရင်က install/cache ပြီးသား app shell ဖွင့်နိုင်ပြီး JS ထဲတွင်ပါသော static question/quiz data နှင့် Question Bank ကို ယေဘုယျအားဖြင့် သုံးနိုင်သည်။

အင်တာနက်မရှိချိန်တွင် **အလုပ်မလုပ်နိုင်သောအရာများ**: `/api/ai` သည် backend/အင်တာနက်လိုသည်။ YouTube ဖွင့်ခြင်းနှင့် thumbnail ရယူခြင်းသည် အပြင်အင်တာနက်လိုသည်။ `/audio/*.mp3` ဖိုင်များကို cache စာရင်းတွင်မပါသောကြောင့် အသံမရနိုင်ပါ။ ပထမဆုံး install/cache လုပ်ချိန်တွင် မရယူနိုင်ခဲ့သောဖိုင်များလည်း မရှိနိုင်ပါ။ ထို့ကြောင့် app အားလုံး offline အလုပ်လုပ်သည်ဟု အာမမခံနိုင်ပါ။

### E. PWA အသစ်ပြောင်းလဲမှုများ

`sw.js` ၏ cache အမည်မှာ `learn-smart-ai-shell-v1` ဖြစ်သည်။ Deployment အသစ်တင်ပြီး service worker ဖိုင်ပြောင်းသွားလျှင် install အဆင့်၌ `skipWaiting()` ဖြင့် worker အသစ်ကို ချက်ချင်းအသက်ဝင်စေပြီး ယခင် `learn-smart-ai-*` cache များကို ဖျက်သည်။ စာမျက်နှာဖွင့်သည့်အခါ အရင် network မှရယူပြီး network မရမှ cache ရှိ index ကိုသုံးသည်။ Browser က deployment အသစ်နှင့် worker အသစ်ကို ရယူအသက်ဝင်စေပြီးနောက် shell အသစ်ကိုသုံးနိုင်သည်။ Browser cache နှင့် ဖွင့်ထားပြီးသား tab အခြေအနေကြောင့် reload သို့မဟုတ် app ကိုပြန်ဖွင့်ရန် လိုနိုင်သည်။ Update အသိပေး pop-up မရှိပါ။

### F. PWA ကိုဖယ်ရှားခြင်း

- **Desktop Chrome/Edge:** App window သို့မဟုတ် browser ၏ installed apps/settings ထဲမှ Learn Smart AI > **Uninstall/Remove** ကိုရွေးပါ။
- **Android:** Home Screen/app drawer ထဲရှိ icon ကိုဖိထားပြီး **Uninstall** သို့မဟုတ် **Remove** ကိုရွေးပါ။ အချို့ version များတွင် Chrome > Settings > Site settings/Installed apps မှ ဖယ်ရှားနိုင်သည်။
- **iPhone/iPad:** Home Screen icon ကိုဖိထားပြီး **Remove App** သို့မဟုတ် **Delete Bookmark** ကိုရွေးပါ။

ဤ menu များ၏ အမည်နှင့် နေရာသည် browser နှင့် OS version အလိုက် ကွာနိုင်သည်။

### G. PWA-ийн одоогийн хязгаарлалт

- Install хүсэлтကို app ကိုယ်တိုင်မထိန်းချုပ်ပါ။ Browser ပံ့ပိုးမှုနှင့် hosting အပေါ် မူတည်သည်။
- Service worker ကို production build တွင်သာ မှတ်ပုံတင်သည်။ Vite development preview တွင် မမှတ်ပုံတင်ပါ။
- Cache ထဲတွင် app shell နှင့် static ဖိုင်များသာ အဓိကပါသည်။ API, YouTube, audio နှင့် ပြင်ပအကြောင်းအရာများကို offline မရပါ။
- စာမျက်နှာဖွင့်ရာတွင် network ကိုအရင်သုံးပြီး shell ဖိုင်များတွင် cache ကိုအရင်စစ်သည်။ Update banner သို့မဟုတ် “update now” ခလုတ်မရှိပါ။
- Browser/OS အားလုံးက standalone ပုံစံ၊ icon နှင့် install menu ကို တူညီစွာပြမည်ဟု အာမမခံနိုင်ပါ။

```text
Learn Smart AI website ကိုဖွင့်ပါ
            ↓
Browser က manifest/service worker ကိုစစ်ဆေးသည် (production နှင့် လိုက်ဖက်သောအခြေအနေတွင်)
            ↓
Install / Add to Home Screen ပေါ်လာပါက ရွေးပါ
            ↓
Learn Smart AI icon ကို စက်၏ Home Screen သို့မဟုတ် app list ထဲထည့်ပေးသည်
            ↓
Icon ကိုနှိပ်ဖွင့်ပြီး အသုံးပြုပါ (ပံ့ပိုးပါက သီးခြား window ပုံစံဖြင့်ဖွင့်မည်)
```
